# ReceiptSplitter

ReceiptSplitter is a Python application that prepares receipt images for OCR.

## Features

- Load PDFs
- Load JPEG/PNG images
- Generate debug images
- Detect receipt regions
- Split multiple receipts
- Prepare images for Google Apps Script OCR
